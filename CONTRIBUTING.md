# Contribuer

Merci de participer au projet escape game. Quelques règles simples :

1. Créez une branche depuis `main` (`feat/...` ou `fix/...`).
2. Copiez `.env.example` vers `.env` — ne commitez **jamais** `.env`.
3. Avant une PR : `make config` et, si vous touchez l’infra, `make test`.
4. Ouvrez une PR vers `main` ; le template checklist vous guide.
5. Poussez **souvent et par petits commits** pour faciliter la relecture.

Documentation détaillée : [docs/devops.md](docs/devops.md) et [docs/runbook.md](docs/runbook.md).
